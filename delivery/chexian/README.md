# 车险小程序增量模块

版本：0.1.0。此目录是独立增量源码，不是已合并原商城、已接通泰康真实报价的生产版。

## 内容
- `uniapp/insurance/`：车险首页、家用车入口、聊天页、历史页、组件和素材队列。
- `backend/`：本地演示服务、会话隔离、图片安全校验、加密保存、资料版本确认、重复提交保护。
- `web-preview/`：电脑浏览器预览页面，支持拖拽/粘贴图片的前端交互。
- `dotnet-bridge/`：原商城身份签发接入示例。
- `tools/`：安全解压、页面注册及素材配置合并工具。
- `docs/`：接口契约、集成步骤、测试报告。

## 本地演示
安装 Python 3.11+，在本目录执行 `start-demo.cmd`（Windows）或 `bash start-demo.sh`（Mac/Linux），浏览器访问 `http://127.0.0.1:18991`。
