# 集成注意事项

1. 不覆盖商城原首页；在原首页适配并引入 InsuranceEntry 组件。
2. 页面注册需合并原 pages.json，保留原 TabBar、条件编译及分包设置。
3. 原商城登录态必须由现有后端签发短期身份，不在小程序内保存保险公司账号密码。
4. 图片导入后先绑定当前车辆和会话，再确认字段；补传图片后必须重新核对。
5. OCR、泰康阶段接口和报价状态必须由原Java业务平台的受保护业务桥接承接；不能把执行器内部租约接口暴露给小程序。
6. 外部报价请求结果未知时必须锁定原任务并人工核对，不得自动重试以免重复建单。
7. 电脑端拖拽只在H5/浏览器页面处理；微信电脑版素材能力需要在目标微信版本实测。
8. 目前提交的页面文件依赖尚未提交的 DevNotice.vue、config.js 等模块，当前目录不是完整可构建工程。
